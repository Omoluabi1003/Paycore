# Contractor statement design

The final demo PDF follows the client's supplied Excel/PDF visual reference: US Letter, pale cyan heading with a green company panel, italic text, fine black table borders, blue-gray section rows, current/YTD earnings and deductions, totals, described charges/reimbursements, then load detail. PayCore's existing mark and ETL GIS Consulting LLC attribution remain. No private reference document, client logo, identity, account, amount or rate is committed or used as demo data.

Typography: the user supplied `tr-century-gothic-italic.zip`, containing TR Century Gothic Italic (PostScript name `TRCenturyGothicItalic`). The export now embeds that unmodified TrueType font and uses its actual character widths for wrapping and numeric alignment. It no longer substitutes Helvetica. This is the uploaded TR variant; no assertion is made that it is the separate Monotype font. The archive contains no Bold Italic face, so headings use the same italic face with a light PDF stroke. A supplied genuine Bold Italic file can replace that treatment later. The renderer retains existing ASCII transliteration behavior; unsupported non-ASCII characters remain a known export limitation.

Font provenance: the generated data module contains the uploaded font bytes, SHA-256 identity, ASCII widths and font metrics. Technical OS/2 embedding flags are zero (unrestricted embedding). The archive has a generic download-site readme rather than a font-specific license grant; the technical embedding flag is not a license determination. No unrelated payroll attachment is included. PDF streams carry the font through FontFile2/ASCIIHexDecode, allowing offline rendering without a locally installed copy.

Only frozen approved-exhibit snapshots supply current figures. YTD uses approved same-company/same-contractor history through the selected year/date. Historical compensation methods remain visible even if the current method changes. Deductions retain category totals plus individual descriptions and references; the category summary is not a second charge. Reimbursements/adjustments remain distinct from deductions. Period-based earnings are not invented as per-load earnings. Excluded loads remain labeled and are not added to eligible totals. No company address, account, payment date, hours or receipt location is invented when those fields are absent from the model.

Short statements fit one Letter page; long tables/descriptions continue with repeated contractor, period, section/column headings and per-page attribution. The PDF is generated locally and deterministically from the snapshot; no external font/image request, new integration, environment variable, database migration or dependency is required. Export remains available only at the final simulated approval stage.

Validation: existing financial/export regressions, added YTD category/method-change and history-scope tests, one-page Letter/italic-font/escaping checks, long-description pagination, valid object offsets, deterministic bytes and immutable input checks. Render and extract text from independently synthetic sample PDFs; never use private client figures in fixtures. Typecheck, production build and final-download browser rehearsal are completion gates.

Rollback: revert the renderer and new tests/documentation to restore the former branded report layout. Financial calculations, approved snapshots and saved drafts require no migration or rollback.
